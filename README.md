# CHIPS Alliance (chips-alliance)

CHIPS Alliance is a Linux Foundation project (founded in 2019) that develops open-source hardware (silicon) and tools, including CPUs, SoC subsystems, peripherals, IP blocks, and FPGA tooling. The Alliance fosters collaboration among 50+ member organizations across industry (AMD, Antmicro, Google, Microsoft, SiFive, Intel, Nvidia, Cisco, Synopsys, Microchip, and others) and academia. CHIPS Alliance hosts more than a dozen technical projects including Chisel, F4PGA, Caliptra, VeeR, Surelog/UHDM, and the FPGA Interchange format.
