# CHIPS Alliance (chips-alliance)
CHIPS Alliance is a Linux Foundation project supporting open source hardware development, fostering collaboration on silicon device designs including CPUs, SoCs, and FPGA tooling. It accelerates innovation and reduces costs in chip development through projects like Chisel, FIRRTL, and OpenROAD.
